# Pivot Reader

A speed reader for iPhone (and any browser). It imports PDF and EPUB files (or pasted text) and shows them one word at a time, with each word lined up on its focus letter.

- Works fully offline once installed: open the site in Safari, then Share → Add to Home Screen.
- No account and no server. Books are stored only in the browser on your device.
- Libraries bundled: pdf.js 3.11.174, JSZip 3.10.1. Fonts: Atkinson Hyperlegible and Literata (SIL OFL).

When you change any file, bump `VERSION` in `sw.js` so installed copies pick up the update.
